## My website

This is the source of my personal website: [af.codes](https://af.codes)

The transparent AF monogram lives in `images/af.png` (1024x1024). Its browser variants are `favicon.png` (96x96) and `favicon.ico` (16x16, 32x32, and 48x48); `apple-touch-icon.png` is the opaque 180x180 Home Screen variant. After changing the logo, regenerate these variants and run `og-image/render.sh` to refresh the social preview.
